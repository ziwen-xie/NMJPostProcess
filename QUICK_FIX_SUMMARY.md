## 📊 Issue 3: Summary Statistics Table

**NEW FEATURE:** Generate statistics for selected spikes

**What it does:**
- Calculates per-ROI statistics (spike count, avg latency)
- Calculates overall statistics
- Saves to CSV: `spike_latency_summary_stats.csv`
- Shows formatted table in GUI

**Example Output:**
```
Summary Statistics for 20-1
============================================================

ROI             Spikes     Avg Latency (s)    Median (s)
------------------------------------------------------------
ROI.14 []       3          25.614             24.287
ROI.15 []       2          30.145             30.145
------------------------------------------------------------
OVERALL         5          27.315             25.614
============================================================
```

**How to use:**
1. Load latency data in Spike Review page
2. Check/uncheck spikes to include/exclude
3. Click **"Generate Summary Stats"** button (new!)
4. View table in dialog
5. File saved automatically

## 📝 Key Points to Remember

### Spike Latency Calculation:
- ✅ Must be **enabled in Settings** before processing
- ✅ Console shows "ENABLED" when running
- ✅ Creates 2 files: `spike_latency_stats.csv` and `spike_latency_detailed.csv`

### Loading Data:
- ✅ Select the **file-specific subfolder** (e.g., `20-1/`)
- ❌ Don't select the parent folder (`analysis_output_...`)
- ✅ Folder must contain both `spike_latency_detailed.csv` and `dff_table.csv`

### Summary Stats:
- ✅ Shows per-ROI and overall statistics
- ✅ Only includes **selected (checked)** spikes
- ✅ Automatically saves to CSV
- ✅ Displays formatted table in GUI
