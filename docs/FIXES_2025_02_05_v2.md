## Issue 1: ✅ Spike Latency Not Computing in GUI

### Problem
User reported that spike latency was not being computed when clicking "START BATCH" in GUI, with no output files created.

### Root Cause
The spike latency calculation feature was correctly implemented, but:
1. The warning message when disabled was not prominent enough
2. No verification message when files were successfully created
3. Users may not realize the checkbox must be enabled in Settings

### Solution
Enhanced feedback throughout the pipeline:

**1. Added Prominent Warning When Disabled** ([GUI_3.py:179-181](GUI_3.py#L179-L181))
```python
if not local_cfg.calculate_spike_latencies:
    print("WARNING: Spike latency is DISABLED - no latency files will be created!")
    print("To enable: Go to Settings -> Check 'Calculate spike latencies'")
```

**2. Added Stimulation Window Display** ([GUI_3.py:182](GUI_3.py#L182))
```python
print(f"Stimulation windows: {local_cfg.stim_windows}")
```
This helps verify the correct stimulation preset is being used.

**3. Added File Creation Verification** ([GUI_3.py:187-192](GUI_3.py#L187-L192))
```python
# Verify latency files were created if enabled
if local_cfg.calculate_spike_latencies:
    latency_file = file_output_dir / "spike_latency_detailed.csv"
    if latency_file.exists():
        print(f"[OK] Spike latency file created: {latency_file}")
    else:
        print(f"[WARNING] Spike latency file NOT created (no valid spikes found)")
```

### How to Use
1. **Enable in Settings:**
   - Go to Settings page
   - Check ☑ "Calculate spike latencies"

2. **Run Batch Processing:**
   - Go to Batch Process page
   - Select your CSV files
   - Click **START BATCH**

3. **Monitor Console Output:**
   ```
   ============================================================
   Processing: 20-1.csv
   Spike latency calculation: ENABLED          ← Verify this!
   Output folder: analysis_output_20250205_203337/20-1
   Stimulation windows: [(30, 50), (80, 100), (130, 150)]
   ============================================================

   [OK] Spike latency file created: ...\spike_latency_detailed.csv
   ```

4. **Check Output Files:**
   - Navigate to: `analysis_output_YYYYMMDD_HHMMSS/filename/`
   - Look for:
     - `spike_latency_stats.csv` (per-ROI summary)
     - `spike_latency_detailed.csv` (individual spikes)

### Key Points
- ✅ Console now shows **ENABLED/DISABLED** status prominently
- ✅ Warning message if disabled explains how to enable
- ✅ Verification message confirms file creation
- ✅ Stimulation windows displayed for validation
- ⚠️ If you see "DISABLED", go to Settings and enable the checkbox!

## Common Issues and Solutions

### Issue: "Spike latency calculation: DISABLED"
**Solution:**
1. Go to Settings page
2. Check ☑ "Calculate spike latencies"
3. Re-run batch processing

### Issue: "No subfolders found"
**Problem:** Selected a file-specific subfolder instead of parent folder
**Solution:** Select the parent `analysis_output_YYYYMMDD_HHMMSS/` folder

### Issue: "spike_latency_detailed.csv not found"
**Problem:** Latency calculation was disabled during processing
**Solution:**
1. Enable "Calculate spike latencies" in Settings
2. Re-process your files
3. Then load the spike review data

### Issue: Some folders skipped
**Check console output** - it will show why each folder was skipped:
- "latency file missing" → Latency calculation was disabled
- "empty latency file" → No spikes with valid latencies found
- "dff_table.csv missing" → Processing did not complete
